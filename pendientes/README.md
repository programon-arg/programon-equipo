# Propuestas pendientes

Acá caen las skills que alguien propuso y todavía no se revisaron. **Nada de esto está
habilitado**: son borradores para que Joaquín los mire.

Una skill es código que corre con los permisos de quien la instala. La revisión no es un
trámite: es leer el fuente completo antes de dejarla entrar.

Ver la skill `buscar-skill` para cómo se propone una.
